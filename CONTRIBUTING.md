# Contributing to IDQA Research

IDQA is being published as a working research proposal. Contributions are welcome when they improve the scientific record rather than merely reinforce the current model.

## Useful contributions

- related work we have missed;
- counterexamples that weaken an IDQA proposition;
- independent examples of assurance gaps;
- alternative explanations for observed phenomena;
- benchmark ideas;
- evidence that a conventional technique already addresses a claimed gap;
- replication attempts;
- terminology corrections;
- methodological criticism.

## Please distinguish

When opening an issue or proposing a change, identify whether the contribution is:

- established literature or standard;
- industry/product claim;
- personal observation;
- hypothesis;
- experimental result;
- interpretation/opinion.

Whenever possible, include a DOI, canonical publication URL, standard identifier or reproducible artifact.

## Privacy

Do not post confidential customer/company information, private-origin cases, credentials, personal data or proprietary implementation details.

## Scope

This repository contains the public IDQA methodology record. It does not automatically open-source OmniQA or other IsenForge implementation details.
