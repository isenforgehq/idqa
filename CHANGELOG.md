# IDQA Changelog

## v0.1 — 2026-09-28

Initial public working specification.

Introduces:
- Intent → Guarantees → Evidence Requirements → Evidence Strategies → Observations → Evidence → Assurance;
- evidence-strategy compatibility with guarantee type;
- explicit composition rule;
- context extending assurance boundaries;
- UNKNOWN / INSUFFICIENT_EVIDENCE as valid assurance states;
- hypothesis that scenarios, automation and executions may be reusable or ephemeral materializations;
- initial research questions and evaluation discipline;
- OmniQA as reference implementation, separate from the methodology.
